# Copia principal del proyecto

La carpeta `D:\DECOM\PAGINA WEB DECOM VILLA DEL RIO` es la copia principal y editable de IPUC Villa del Río por instrucción del usuario.

- Realizar aquí los nuevos cambios y mantener esta carpeta actualizada antes de entregar o publicar una actualización.
- Si hace falta trabajar en otro checkout, integrar y verificar el resultado en esta copia principal antes de finalizar. Conservar cualquier cambio local existente.
- Reutilizar este proyecto y su backend. Consultar `LEEME-PARA-EDITAR.md` para ejecutar, comprobar y organizar el código.
- Mantener `privado/`, `material-decom/` y `respaldo-desarrollo/` fuera de Git y del despliegue. No sobrescribir la web actual con los respaldos antiguos.
- Al terminar, dejar abierto en VS Code `IPUC-Villa-del-Rio.code-workspace`, con el código completo editable de esta carpeta.
- Comunicar los cambios y comprobaciones de forma breve; economizar tokens.
